# Premium Hub Releases

This repository is reserved for distributing authorized Premium Hub Android APKs through [GitHub Releases](https://github.com/mangalsingh725185-jpg/premium-hub-releases/releases).

The initial repository contains only this README and a restrictive `.gitignore`. Application source code, APK binaries, private configuration, signing keys, and local project notes are excluded from Git.

Approved APKs belong in GitHub Release assets, not in repository commits. Release notes should identify the app package, version, file size, and SHA-256 checksum. Android installation requires normal user consent.

Only APKs with confirmed redistribution permission may be uploaded or published. The third-party YouTube Premium catalog APK is not approved for distribution; a catalog authorization flag alone does not establish redistribution rights.
